# 🚀 Foreign Delivers - Premium Food Delivery App

Foreign Delivers is a high-performance, full-stack food delivery application built with **Expo (React Native)** and **Node.js (Express)**. Designed for a **smooth, modern, and visually rich ordering experience**.


## ✨ UI/UX Improvements

* **🌙 Modern Dark Mode**
  Clean dark theme with soft gradients and vibrant accent colors

* **🧊 Minimal Glass UI**
  Subtle blur cards for food items and menus

* **🍔 Enhanced Food Cards**

  * Image-focused design
  * Price & rating clearly visible
  * Smooth horizontal scrolling

* **🛒 Improved Cart Experience**

  * Floating cart button
  * Real-time price updates
  * Simple checkout flow

* **🌀 Smooth Interactions**

  * Button animations
  * Screen transitions
  * Add-to-cart feedback

## 📱 Key Features

* **🔐 Authentication**: Login & Signup screens
* **🏠 Home Screen**: Categories & featured meals
* **🍽️ Menu Browsing**: Clean and fast navigation
* **🛒 Cart & Checkout**: Easy order placement
* **📦 Order Tracking**: Basic status updates


## ⚡ Performance

* Fast navigation and smooth scrolling
* Optimized API communication
* Lightweight and responsive UI


## 🛠️ Tech Stack

* **Frontend**: React Native, Expo
* **Backend**: Node.js, Express.js
* **Navigation**: React Navigation
* **Styling**: React Native StyleSheet


## 🚀 Getting Started

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npx expo start
